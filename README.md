An ExileCore / PoeHelper plugin for Path of Exile that draws labels and helpers on the Atlas.

## Features
- Map name and tier labels on Atlas nodes; optionally only uncompleted maps
- Highlight maps by name list or per-node tick, with configurable colours
- Route drawing (paths) to chosen maps from the first map you still have to run
- Kirac shop panel (current/next shop tier, objectives needed), optional "+1" marks on maps that count toward objectives
- Kirac shop refresh alert in the hideout, with Acknowledge
- Random Content alert: when a Random Content node is shown on the Atlas, a window alerts you with an Acknowledge button. It alerts again if the node disappears (you ran it) and returns
- Maven farm: choose an ordered list of maps (the "Maven" tick in the map list, reorder in the "Maven farm" section); the first one the Maven hasn't witnessed yet is highlighted on the Atlas
- Quadrant picking for Maven farming: the map list shows which quadrant (NW/NE/SW/SE) each map is in and can be filtered by it, so you can pick the maps for your Maven farm list from one quadrant, or tick Highlight on all maps of a quadrant to find them on the Atlas
- Lowest-tier summary and marking, unique-map bonus handling
- Show/hide groups: pinnacle bosses, league bosses, other special nodes, watchstone slots, random content
- Map list window with Highlight / Path / Show on Atlas ticks per node
- Avoids drawing over the right-hand panel and game UI
